# Learn With Me

This repository is a collection of my **learning journey as a developer**.

Instead of keeping everything I've learned scattered across notes, bookmarks, and random files, I wanted one place where I could document the concepts I've explored across different areas of software engineering.

You'll find topics covering:


* [**Learning Git**](/learning-git/Readme.md)
* [**Coding with AI: Power, Risks and Responsibility**](/Coding-with-AI-Power-Risks-and-Responsibility/Readme.md)

I will keep upoloading my journey from time to time

I'm writing these notes based on things I've learned, problems I've faced, mistakes I've made, and approaches I've used in real projects.

This isn't meant to be a perfect reference or a collection of everything there is to know.

It's more about documenting **how my understanding evolved**  from learning simple concepts to understanding the trade-offs behind more complex engineering decisions.

My goal is simple:

> **Learn → Understand → Build → Make mistakes → Document → Improve**

And hopefully, these notes can also help someone else who is learning the same concepts along the way.
